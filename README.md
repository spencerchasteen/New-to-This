# New-to-This
BA workflow for processing Liberty IPP factor updates. Covers receiving actuarial factors, validating changes, updating Jira, modifying ETM tables, promoting through Dev/Test/Stage/Prod, obtaining sponsor sign-off, testing renewals via SAS/PAW/SoapUI, and validating production. Applies to Dwelling (H3), Tenant (H4), and Condo (H6) policies.
